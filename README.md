# Purrfiles

> Define entity model and provide shared extraction tooling.

Home of meta service, entity models, and the extraction tooling shared by Noodlestan docs sites.

**Keywords:** metadata, extraction, entities, purrception.

## Packages

| Package                          | Path                       |
| -------------------------------- | -------------------------- |
| `@noodlestan/purrfiles-entities` | `libs/purrfiles-entities/` |
| `@noodlestan/purrfiles-extract`  | `cli/purrfiles-extract/`   |

Both move here from Art MD with their records and knowledge intact.

## Development

### Scripts

- **$** `npm run lint` — Check formatting across the repository.
- **$** `npm run ci` — Run root lint and every package's CI.
